# Tender Finder Frontend

React + Vite + TypeScript + Tailwind CSS.

## Локальный запуск

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173.

Прокси на бэкенд настроен в `vite.config.ts` (по умолчанию `http://localhost:8000`).

## Сборка для продакшена

```bash
npm run build
```
